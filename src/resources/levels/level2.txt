TIME_LIMIT 180.0
PROMPT Look at the source colors and think about how different mixtures might yield the varied shades needed by the sinks.
NODE SOURCE S_RED 100 100 PRODUCES=RED
NODE SOURCE S_BLUE 100 300 PRODUCES=BLUE
NODE SOURCE S_YELLOW 100 500 PRODUCES=YELLOW
NODE PROCESSOR P_ORANGE 400 150 RECIPE=RED:1,YELLOW:1->ORANGE:1 DELAY=4
NODE PROCESSOR P_PURPLE 400 300 RECIPE=RED:1,BLUE:1,->PURPLE:1 DELAY=4
NODE PROCESSOR P_GREEN 400 450 RECIPE=BLUE:1,YELLOW:1->GREEN:1 DELAY=4
NODE SINK SINK1 750 200 DEMAND=ORANGE:1,PURPLE:1
NODE SINK SINK2 750 400 DEMAND=GREEN:1
